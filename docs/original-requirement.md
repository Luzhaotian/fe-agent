# 说明

## 这是一个全栈智能体，让我描述一下这个的功能

!!!首先这个 agent 有几个角色：项目经理（统筹员）、架构（非业务改动 + 接口文档）、后端架构、前端架构（主要前端开发）、测试员、审查员、产品（需求编写、整理）

### 项目经理（统筹员）

- 接收需求分发给产品；需求审查通过后分发给架构产出接口文档
- 接口文档轻量审查通过后，先分发后端架构与测试员；后端通过后再分发前端架构与测试员
- 收集提问分级：低级自己处理，中级查经历，高级交用户
- 审查结果同理分级处理；非业务改动转架构

### 产品（需求编写、整理）

- 整理/拓展需求，含后端能力与数据实体；网址需求可提取
- 交给项目经理 → 审查员审查，按反馈整改

### 架构（系统架构）

- 评估并处理非业务改动（目录/依赖/基建）
- 产出接口文档；开发前必做评估，过程中可按需介入
- 纯前端可标注无需后端

### 后端架构

- 按接口文档实现后端；生成/遵循 backend skills；优先复用已有模块
- 完成后经项目经理交审查员审查并整改

### 前端架构（主要前端开发者）

- 按需求 + 接口文档开发前端；生成/遵循前端 skills；优先通用组件
- 严格按项目已有结构，不自创样式体系

### 测试员

- 先后端用例、再前端用例；交审查员审查

### 审查员

- 审需求；轻量审接口文档（路径/入参/出参/错误码）；审后端/前端代码与用例
- 反馈分级给项目经理

### 每次都要执行的点

- 每个角色执行都要有日志
- 执行完提取知识点写入对应角色知识库
- 接口文档落盘到 `.fe-agent/artifacts/api-doc.md`
